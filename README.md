--Мой проект аудиобот который может модернизировать твое аудио--

в нем есть команды которые понятно обьясняються пользователю
/help -- Показывает весь список команд
/translate -- Переводит твое аудио
/short -- Сокращает твое аудио
/show -- Показывает последний текст аудио
/listen -- Начать запись
/language -- Выбрать язык для перевода
/len -- Выбрать длину записи в секундах

Если пользователь что нибудь не сделает бот его об этом предупредит!
бот оформлен удобно и понятно что любой пользователь смог им пользоваться 
Я выбрал эту тему проекта так как мне понравилось работать с ботом и с аудио
